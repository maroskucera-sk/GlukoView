GlukoView

Pripoj dosku káblom k počítaču a nahraj firmvér. Visual Studio, PlatformIO ani Python netreba.

Plug the board into a computer and flash the firmware. Visual Studio, PlatformIO and Python are not required.

  • Chrome alebo Edge na počítači. Firefox, Safari a telefón nie.
  • Solo je kruh. V zozname portov je prevodník CH343. Keď port nie je, nainštaluj ovládač CH343.
  • Duo je široký displej. Keď sa nahrávanie nechytí, podrž BOOT, stlač RESET, pusti BOOT a skús znova.
  • Chrome or Edge on a computer. Not Firefox, Safari or a phone.
  • Solo is the round display (CH343). Install the CH343 driver if the port is missing.
  • Duo is the wide display. If flashing does not start, hold BOOT, press RESET, release BOOT and try again.
